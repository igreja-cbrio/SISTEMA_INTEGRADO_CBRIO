Como os números são apurados. Atividade = histórico de commits dos repositórios públicos igreja-cbrio/SISTEMA_INTEGRADO_CBRIO e igreja-cbrio/whitelabel-erp (branch principal). Identidades consolidadas por pessoa (cada um comita com mais de um nome): Matheus Toscano (mtoscano99), Marcos Paulo (MarcosPaulo1) e Claude (IA) (co-autoria + bot). "Merge" = commit com 2+ pais (PR integrado). "Assistido por IA" = commits com o rótulo Co-Authored-By: Claude.
Custos são estimativas editáveis (USD convertido pelo câmbio acima). O acumulado usa os meses decorridos desde o início; a projeção de 12 meses = recorrente × 12 + custos pontuais. Ajuste com as faturas reais em scripts/system-report/config.json.
Regenerada automaticamente pela GitHub Action system-report (diária + a cada push na main). O botão "Atualizar ao vivo" rebusca o GitHub no seu navegador.
